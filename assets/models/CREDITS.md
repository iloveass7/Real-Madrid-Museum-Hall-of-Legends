# Statue source models

Both are three.js sample assets, downloaded from the three.js repository and
edited in `src/world/statue.js` (re-posed through the skeleton, re-proportioned,
dressed in carved kit, rendered in stone).

| File | Origin | Licence |
|---|---|---|
| `Xbot.glb` | Mixamo "X Bot" rigged humanoid, shipped as a three.js example model (`examples/models/gltf/Xbot.glb`) | Mixamo / Adobe free-use for the three.js samples |
| `LeePerrySmith.glb` | Lee Perry-Smith head scan, shipped as a three.js example model (`examples/models/gltf/LeePerrySmith/`) | CC-BY 3.0 — Infinite Realities / Lee Perry-Smith |
